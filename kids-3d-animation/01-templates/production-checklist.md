# Daily production checklist — Day {{DAY}}

Print it, work down it. Three videos a day is only sustainable if you never have to
decide what to do next.

---

## Morning — write (60 min)

- [ ] Pick three concepts from the idea bank (`00-system/seo-metadata-system.md`)
- [ ] **A** — lyrics written, syllable-checked, chorus repeats ≥ 4×
- [ ] **B** — script written, five-act shape holds, elder states no moral
- [ ] **C** — beat sheet written, gag lands by 0:02, empty frame placed

## Morning — audio (30 min)

- [ ] A — Suno, 4 takes, pick on hook memorability
- [ ] B — three instrumental cues (theme / ostinato / elder). **No cue for Act 3.**
- [ ] B — narration + dialogue recorded
- [ ] C — Suno funk loop, 6 takes, pick the one **with stop-hits**
- [ ] All Suno IDs written into the episode `suno.md`

## Midday — stills (45 min)

- [ ] Character reference sheets attached to every generation
- [ ] Lock blocks pasted **verbatim**, not paraphrased
- [ ] Lighting stage stated in every prompt
- [ ] Universal negative prompt on every generation
- [ ] Quality gate passed on every still (chest star, strap, glasses, paw count, no text)
- [ ] Two keyframes generated for every hard-motion shot

## Midday — animate (start before lunch, ~60 min wall time)

- [ ] **All three videos queued in parallel** — this is the only step where waiting dominates
- [ ] A → Kling 3.0 Turbo · B → Veo 3.1 · C → Veo 3.1 vertical
- [ ] Motion prompts kept short
- [ ] First/last-frame conditioning used on the impact shots

## Afternoon — edit (45 min)

- [ ] A — cross-dissolves between every shot, volume descends to the end
- [ ] B — Act 3 silence preserved, score ducked 10 dB under narration
- [ ] C — every impact on a downbeat, empty frame held the full 2 s
- [ ] A: −16 LUFS · B: −14 LUFS · C: −13 LUFS
- [ ] C mix checked **on a phone speaker**

## Afternoon — thumbnails (15 min)

- [ ] A — purpose-built still, not a frame grab. Five countable things if it's a count.
- [ ] B — no text, subject left third, hero object right third, subject **not** lit warm
- [ ] C — cover frame selected from the video at the gag peak
- [ ] `node kids-3d-animation/tools/render-thumbnails.js` → composite overlays
- [ ] Blur test at 120 px on all three
- [ ] The three sit visibly apart from each other **and** from the last 20 uploads
- [ ] Exported JPG q90, each under 2 MB

## Evening — upload (15 min)

For each of the three:

- [ ] **Made for Kids: Yes**
- [ ] Title from the formula, under 60 characters, no keyword chains
- [ ] Description: first 150 characters front-loaded, chapters, **full chorus lyrics** (A)
- [ ] 10–15 tags: broad + specific + brand
- [ ] Playlist assigned
- [ ] Altered-content / AI disclosure set
- [ ] Scheduled: C 07:00 · A 17:00 · B 19:00
- [ ] Compliance checklist run (`00-system/compliance-checklist.md`)

## Weekly

- [ ] Watch one of your own videos end to end, unscrubbed, as a parent would
- [ ] Check average percentage viewed on the story slot (target 50–70%)
- [ ] Look at the last 20 thumbnails as a grid — do any two blur together?
- [ ] Swap the thumbnail on anything under 4% CTR at 48 h. **Change one variable.**
- [ ] Add any new world facts to the continuity list in `00-system/character-bible.md`

---

## The one rule

If you're shipping filler to hit the number, **ship two instead of three.** A strong focus
on low-quality made-for-kids content can remove the whole channel from the Partner
Program — the volume is worthless without the floor.
